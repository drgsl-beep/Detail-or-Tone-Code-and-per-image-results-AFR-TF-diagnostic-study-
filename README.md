# Detail-or-Tone-Code-and-per-image-results-AFR-TF-diagnostic-study-
Code and per-image results for the paper “Detail or Tone?”. Shows that the adaptive fractional-order stage in the AFR-TF image restoration pipeline acts as a tone curve, not a detail enhancer. Includes scripts for every table and figure, CSV results (synthetic, UIEB, RESIDE-SOTS, LOL-v2), seeds and split rules.
